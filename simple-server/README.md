# حکم آنلاین (Hokm Online) - نسخه Pure JS

## ویژگی‌ها
- ۴ بازیکن + ۱ ناظر + بیننده
- تایمر ۵ دقیقه‌ای برای پر شدن روم
- ساختار رفت و برگشت (۲ دست + دست سوم در صورت تساوی)
- هر دست تا ۵ ست (دست سوم ۳ ست)
- قوانین کامل حکم (تعیین حاکم، حکم، پیروی از خال، کوت)
- ضد تقلب سمت سرور

## نصب و اجرا روی سرور خودت

```bash
cd simple-server
npm install
node server.js
```

سپس در مرورگر برو به:
http://YOUR_SERVER_IP:3001

## نحوه بازی
1. یک نفر «ساخت روم جدید» می‌زند → کد ۶ حرفی می‌گیرد
2. بقیه با وارد کردن کد و انتخاب نقش (بازیکن / ناظر / بیننده) وارد می‌شوند
3. وقتی ۴ بازیکن کامل شد، دکمه «شروع بازی» ظاهر می‌شود
4. حاکم خال حکم را انتخاب می‌کند
5. بازی شروع می‌شود

پورت پیش‌فرض: 3001 (می‌توانی با PORT=xxxx تغییر بدهی)
